AUDIO INPUT

Start with a recording

When you analyse a recording, it is sent to this app's server and processed in memory; the app does not retain the audio. In a hosted deployment, use only recordings you have permission to share. The optional SUPERB model downloads about 757 MB of model files on first use.

Input-gradient maps are generated for local CNN checkpoints; the pretrained wav2vec2 model does not provide this sensitivity view.

Training details

The SUPERB model is available separately in the model selector. Its English IEMOCAP-derived head has four classes only (neutral, happy, angry, sad), downloads about 757 MB on first use, and has no EmotionLens validation or calibrated rejection threshold. Its model card says Apache-2.0; IEMOCAP source-data terms still apply.

To train the local eight-class RAVDESS model, obtain the speech dataset, extract it to datasets\RAVDESS, then open PowerShell in the project’s backend folder and run:

python -m app.training --dataset ..\datasets\RAVDESS --architecture cnn_lstm --epochs 20 --batch-size 16 --seed 42 --compare --robustness

After training completes, restart the app. Until then, audio features can still be inspected, and the separate pretrained model can be selected.

RESEARCH EXTENSIONS

Implemented comparisons and data-dependent work

CNN–BiLSTM with temporal attention

Implemented as a trainable model option; compare with CNN and CNN–LSTM using identical speaker splits.

Multilingual evaluation

Not yet supported: currently implemented datasets are acted English speech. Language-specific corpora and validation are needed.

Multimodal fusion

Not enabled; suitable consented, aligned speech/video/text data and an independent evaluation are not available.

Pretrained audio embeddings and calibrated probabilities

Not enabled or evaluated; model licensing, compute, and calibration evidence are required.

Speaker-reference adaptation

Reference feature deltas are available; no evidence currently shows improved emotion classification from adaptation.
